# 🛒 의류 필요성 기반 스마트 위시리스트 (Smart Wishlist App)

> **소프트웨어개발실습1 과제** - 충동구매를 방지하기 위해 앱이 객관적으로 의류의 필요성을 진단하고 예산을 관리해 주는 모던 웹 앱 시스템입니다.

---

## 📱 서비스 실행 방법 (How to Run)

이 프로젝트는 별도의 설치 없이 **브라우저에서 즉시 실행 가능한 단일 웹 앱**입니다. 아래 방법으로 간편하게 실행해 볼 수 있습니다.

1. 왼쪽 상단의 코드 목록에서 **`index.html`** 파일을 클릭합니다.
2. 코드 우측 상단의 **`[Raw]`** 버튼을 누르거나 코드를 전체 복사합니다.
3. 바탕화면에 메모장을 열고 붙여넣은 뒤, 파일 이름을 **`index.html`**로 저장합니다.
4. 저장된 `index.html` 파일을 더블클릭하면 크롬/엣지 브라우저에서 진짜 앱 같은 세련된 다크 모드 UI가 실행됩니다!

---

## ⭐ 주요 핵심 기능

### 1. 🤖 AI 스마트 필요성 자동 진단 (인사이트 핵심 기능)
* 사용자가 점수를 주관적으로 매겨 합리화하는 것을 방지하기 위해, 앱이 냉정하게 **3가지 다각도 질문**을 던집니다.
  * *대체 가능성 (옷장에 비슷한 옷이 있는가?)*
  * *활용도 (일주일에 몇 번이나 입을 것인가?)*
  * *지속성 (내년에도 유행 안 타고 입을 수 있는가?)*
* 알고리즘을 통해 **10점 만점 기준의 필요성 스코어를 소수점 첫째 자리까지 자동 연산**하여 부여합니다.

### 2. 📊 유동적 쇼핑 예산 설정 대시보드
* 상단의 예산 대시보드 영역을 터치(클릭)하면 부드러운 앱 감성 팝업 모달이 올라옵니다.
* 고정된 금액이 아니라 사용자의 현재 자금 상황에 맞게 **쇼핑 예산을 실시간으로 직접 변경 및 관리**할 수 있습니다.

### 3. 🔄 필요성 점수 기반 실시간 자동 정렬
* `[필요성 점수순 ⬇️⬆️]` 버튼을 누르면 AI가 판단한 필요성 고득점 아이템(지금 당장 가장 사야 하는 옷) 순서대로 카드가 실시간 배치 전환됩니다.

### 4. 🎨 트렌디한 모바일 프리미엄 UI/UX
* 투박한 일반 표(Table)나 자바 Swing 디자인에서 완전히 탈피하여, 실제 패션 커머스 앱(무신사, 인스타그램 등) 감성의 **다크 모드 카드 레이아웃과 네온 셀렉트 효과**를 구현했습니다.
